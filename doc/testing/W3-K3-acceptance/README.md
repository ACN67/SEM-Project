## 复验

从仓库根目录安装 knowledge/export/quality 的依赖与既有契约测试依赖后，提供 W5 清单中 EV-R02-SAIC-2024-P13 对应的原始 PDF。

```powershell
python -m backend.tests.integration.verify_w3_k3 <原始PDF路径> <输出目录>
```

脚本检查原件 SHA-256，使用 W3 实际解析物理第 13 页并重复解析核对 ID。手工绑定该摘录中费用化、资本化研发投入及合计金额，冻结快照后调用质量图表渲染器和 K3 Word 导出。数值换算使用 Decimal，文本解析本身未自动核验或生成指标。

真实原件哈希为 c980b2d827f372b5b90742e299d609345c83342584901c96ea95891c43f4ab3f。
证据 ID 为 54b81f82594425072dcd637a3d13f76228b9702dd6be14807d409de47f54ad4e。
合计 21,813,090,045.30 元，物理第 13 页，同一来源在正文、图注、参考来源复用编号 [1]。

移除资本化研发投入（rd-2）的证据后，导出在读取 PNG 前返回 EXPORT_FAILED，details 包含 chart1、a1、rd-2。正反例机器可读结果见 result.json。

Word 实际打开后更新目录并渲染三页；第 3 页见 report-page.png。高精度金额轴刻度使用有限有效数字显示，并根据标签宽度预留左边距，底层指标保留完整数值。
