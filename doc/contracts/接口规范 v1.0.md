## 前端到后端

所有路径以 /api/v1 开头。日期按 ISO 8601，任务时间含时区。ID 均为不透明字符串。以 Schema 的 required 区分「必须出现但可以为 null」与「可以省略」。列表参数 page 从 1 开始，limit 默认 20、上限 100；超出最后一页返回空 items 和准确 total。版本、报告、文档按创建时间倒序，同时间按 ID 倒序；模板按 template_id、version 排序。详情的关联资源必须属于路径指定的报告，否则返回 404。

|操作|成功结果与消费方式|
|---|---|
|POST /admin/session；DELETE /admin/session|同源登录提交 credential，204 设置 sem_admin cookie；退出销毁服务端会话并清除 cookie。有效期 8 小时，HttpOnly、SameSite=Strict，HTTPS 环境启用 Secure；有副作用的管理请求检查 Origin。凭据或会话缺失/无效返回 401，权限或来源校验失败返回 403。|
|POST /documents；GET /documents、/documents/{document_id}|表单 file 携带原件，metadata 是 application/json 部分。首次入库返回 202；内容完全相同复用既有版本，返回其实际状态。document_id 详情指向最新版本；status_url 指向本次具体版本的查询地址，重复上传也可安全轮询。格式不支持 415，超过 50 MiB 为 413。|
|GET /templates；GET /templates/{template_id}/versions/{version}|模板含独立 input_schema，使用五份表单 Schema 的对应内容，连同内部 $defs 一并返回。分别见 [表单定义](../../shared/contracts/schema/forms)。普通文本、企业数组、日期、枚举按 Schema 生成表单。包含必需政策判断的模板将 as_of 加入 required 并限制为 date 字符串。|
|POST /reports；GET /jobs/{job_id} 及章节预览|创建时后端锁定该 template_id 对应的当前已部署版本和资料集合，返回 202 与 status_url。只有报告类型与模板一致且通过模板 input_schema 和业务校验才入队。每 2–5 秒轮询。章节预览在本章检查完成前 content=null。|
|GET /reports、报告详情、版本列表及版本详情|列表用 ReportSummary；按 current_version_id 读已保存版本；没有首版时该值为 null。版本索引返回分页 Version。|
|PATCH 章节；POST 章节 regenerate|PATCH 替换整章 blocks，带 base_version_id。200 响应同时含 new_version_id、stale_chapter_ids、exportable。重写返回任务；scope=chapter 仅处理目标章，dependents 处理过期下游章。版本在接受和写入时均校验。|
|POST 任务 cancel、retry|取消返回最新 JobDetail；已取消重复取消返回同一状态。只重试可恢复的失败任务，产生新 job_id，previous_job_id 指向原任务；其他终态返回 409。|
|POST 指定版本 exports；GET 导出详情、download、版本 assets|格式为 docx/pdf，返回 202。READY 时提供下载地址和 SHA-256；失败保留原版本，使用新幂等键重开导出。下载尚未就绪返回 409。图表资源响应 image/png；内部 storage_key 一律不外露。|

创建、重写、重试、导出均带 Idempotency-Key（1–128 个字符）。后端以操作、目标资源和键建立唯一记录，对验证后的请求（含默认值）按排序键的 UTF-8 JSON 计算 SHA-256。同键同请求返回首次受理响应，同键异体返回 409 IDEMPOTENCY_CONFLICT。记录保留至所属报告删除。先查已受理记录再决定是否创建资源，其中写入与入队同事务。

参数错误统一 422 VALIDATION_ERROR，details.errors 为数组，每项为 path（JSON Pointer，如 /companies/1）、message（中文原因）。HTTP 校验层要将框架默认错误转换为 Error。模板不存在 404 TEMPLATE_NOT_FOUND，资源不存在 404 RESOURCE_NOT_FOUND，版本冲突用 [409 样例](../../shared/contracts/fixtures/conflict.json)。异步失败通过轮询返回 200 和资源内的 error，HTTP 503 表示查询或受理服务本身不可用。空检索正常返回空集合。

## 内部交接

所有服务签名使用同步 Python Protocol，Worker 在线程或工作进程中调度阻塞调用。服务异常封装为 ServiceError(ErrorInfo)。Worker 是唯一的模型重试负责人，单次模型请求超时 60 秒；暂时故障最多额外尝试两次，格式错误最多修复一次，所有尝试共享总上限三次。模型输出、检索或渲染服务均不得自行推进 Job。渲染仅写临时文件并回传 storage_key、sha256、size_bytes，后端校验并原子登记下载资源。

- 检索：filters 同一字段内取并集，不同字段取交集；空筛选数组表示该条件不限。source_version_ids 必须显式提供，空数组表示无可用来源。top_k 范围 1–50，超限拒绝。按得分降序、evidence_id 升序去重排序。get_metrics 返回命中冻结集合的指标，跨主体同名指标保留独立 ID。
- 指标：原始值与规范值用十进制字符串；source_evidence_ids 统一使用数组，可表达派生值多来源。同比使用同主体同口径上年同期值，百分比数值按 100 倍记，显示两位小数。限范围外比较期只供计算，不混入正文的研究范围；基数为零返回缺口。派生项携带 formula_id 和 input_metric_ids，输入与最终来源都能在快照解析。
- 证据包：编排层获取实际前置章，按本章任务检索并计算，再附上已核验事实和前章摘要。Summary.text 保存摘要文本，evidence_ids、metric_ids 指向本次包内实体。模板任务 section_key 用于匹配，冻结大纲中的 depends_on 使用实际 chapter_id；必须无悬空依赖、无环。
- 写作与图表：章内稳定 block_id 维持布局。模型可提出 ChartRequest，图值由质量模块读取指标计算；成功时 chart_ref 指向最终 Chart，缺少可选指标时用说明段落替代。正文数值、表格数值、摘要继承引用均须复核。程序检查见 [交接校验](../../backend/app/contracts/validation.py)。
- 版本：编排层可先分配 version_id，构造内存候选并执行 validate_report，再以同一事务写入最终 quality、exportable 和当前版本指针。编辑只允许引用基版本内可解析的证据、指标和资源。下游按依赖传递标记过期。导出资格同时要求必需章齐全、无过期章、所有必需检查已运行且无 BLOCK。
- 任务：QUEUED → RUNNING → COMPLETED 或 COMPLETED_WITH_WARNINGS；失败为 FAILED，取消为 CANCELLED。仅 RUNNING 携带 stage。非终态 result_version_id=null；失败 error 携带原因。每 15 秒续心跳，超过 90 秒的遗留运行项按 WORKER_LOST 恢复，旧 attempt 永远不能提交。取消与最终保存竞争时以首次成功的条件更新为准。
- 权限：研究员在可信演示环境可读报告和证据，只有资料导入需要管理会话；资料和输出均限本项目公开样例。上传临时文件由导入任务持有到解析完成；索引与元数据都写成功才公开 READY。

## 验证与版本维护

从仓库根目录安装 backend/tests/contract/requirements.txt 中依赖，执行 python scripts/export_contracts.py --check 和 python -m unittest discover -s backend/tests/contract。重新生成 Schema 使用 python scripts/export_contracts.py。Pydantic 模型是字段定义来源，OpenAPI 是 HTTP 消费者入口；文档与接口样例同批更新。改变既有字段含义、废弃字段、收紧必填要求或更改错误语义时升级接口主版本，并为现有消费者提供迁移。
