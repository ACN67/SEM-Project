# K1 模板接线与中文导出探针

## 模板接线

启动时创建 `TemplateCatalog()`，接口读取使用 `get_template(template_id, version)`。新任务先用共享 `Spec` 解析表单，再调用 `validate_request(spec, version)`，之后把同一版本的模板交给大纲服务。历史快照仍使用其冻结版本。

A、B 可分别用 `templates/examples/industry_analysis.json` 和 `templates/examples/enterprise_comparison.json`。A 的政策环境章要求截止日，模板 Schema 只接受 date 字符串。B 仍使用共享的对标表单约束。计划执行依赖在内容模板中以 section_key 声明，冻结大纲使用 chapter_id。

## 本地 PDF 试样记录

2026-11-23 在当前 Windows 开发机用 LibreOffice 26.8.3.1 将同一个中文 DOCX 试样转换为 PDF。输出共一页，检查了中文标题和正文、表格数值、中文图注及参考文献编号，PDF 字体检查确认嵌入 Microsoft YaHei 等字体。试样属于转换器可行性验证。正式快照渲染、PDF 生成服务及目标部署机复测由后续任务完成。

试样 PDF SHA-256 为 `85f75294808c9db8d7f4f8b6f1eb60ad85a3851933ec4ffefa0b02c71bd364aa`。数值取中汽协同口径公开数据，2024 原文位于生态环境部年报 PDF 的第 8 个物理页。[2022 数据](https://www.ndrc.gov.cn/fggz/cyfz/zcyfz/202301/t20230131_1348148_ext.html) · [2023 数据](https://app.www.gov.cn/govdata/gov/202401/12/511083/article.html) · [2024 原件](https://www.mee.gov.cn/hjzl/sthjzk/ydyhjgl/202512/W020251203577003736659.pdf)

从仓库根运行。试样使用 python-docx 1.2.0 与 Pillow 13.0.0，生成文件放入新建的本机临时目录。转换可使用系统或独立解包的 LibreOffice。

```powershell
python -m pip install python-docx==1.2.0 Pillow==13.0.0
$out = Join-Path ([IO.Path]::GetTempPath()) ("sem-k1-" + [guid]::NewGuid().ToString("N"))
python scripts/probe_chinese_export.py $out "$env:WINDIR/Fonts/msyh.ttc"
$profile = ([uri](Join-Path $out "profile")).AbsoluteUri
& soffice.com "-env:UserInstallation=$profile" --headless --convert-to pdf --outdir $out (Join-Path $out "k1-probe.docx")
```
